Void Boot Web Installer

Select the extracted payload folder from the Void Boot ZIP, then choose the destination folder. The installer copies only the included menu, theme and profile files.

Important: This is a menu deployment preview. It does not install GRUB, create EFI boot files, partition or format a drive, or make a USB bootable.

For a terminal installer, use install.sh on Linux/macOS or install.ps1 in PowerShell from the extracted ZIP.
