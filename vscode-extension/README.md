# Void Memingo for Visual Studio Code

Basic language support for Void Memingo `.void` scripts.

## Features
- Recognizes `.void` files
- Highlights comments, `let`, `print`, strings, and integer literals
- Provides starter snippets
- Runs the active file with **Void Memingo: Run Current File**

## Requirements
Install the Void Memingo CLI and ensure the `void` executable is available on PATH.

## Package
Install `@vscode/vsce` and run `vsce package` in this directory. Then use **Extensions: Install from VSIX...** in VS Code.
